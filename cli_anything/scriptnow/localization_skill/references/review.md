# 审校与交付

先读实际稿件，再给结论。把结构检查与文学判断分开，不为主观判断虚构百分比。

## 两遍审核分离（Pass 1 / Pass 2）

**正文生成和质量审核尽量分开**。单章循环里的"写完后 10 项自查"（见 [workflow.md §6](workflow.md)）是 **Pass 1 机械自查**（拼音残留 / 公制残留 / 对话标签黑名单 / POV 一致…）；本文件下面列的审校维度是 **Pass 2 文学审核**。

两遍用不同镜片：
- **Pass 1**：查错。每章写完立即过，不放行则不进合并稿。
- **Pass 2**：查好不好看。在合并稿交付后、卷结束后、全书终审时过。

两遍混在一起，查错会挤走查好看的注意力。Pass 2 的问题落到问题清单里，具体给到哪一章哪一段回修，不交"整体感觉平"的话。

## 审校维度

- **来源与范围**：是否读全本轮必要片段；章节对应、人物身份和关键事件是否有出处；漏读与推断有没有说明。
- **因果与文化**：新制度是否真能支撑行动，人物有没有合理替代选择，旧习惯是否只换了名字；迁移是否破坏作者保护的体验。
- **连续性**：人名别名、身份、关系、时间、知识边界与伏笔是否一致；检查正文，不仅检查备注。
- **POV 一致性**：全章/全书是否锁定在项目索引登记的 POV 承载角色上？有没有中途跳人称、跳到另一个角色内心？双 POV 模式下是否按整章切换、章首有明示？
- **语言与声音**：目标语言中对话是否符合人物和关系，英文对白每句是否 ≤15 词，叙述是否保持 POV，修辞是否起作用，是否存在重复反应或解释腔。检查本地俚语与习惯表达是否符合地区、年代、职业、关系和场合，是否改变原句的讽刺、挑衅或亲密意味；整段连读而非只查单词。不要为了"自然"把所有角色改成同一口吻。
- **对白质量**：按 [对白五维](dialogue.md) 完整扫一遍 —— 行动性、包裹层、潜台词、声线差异、节奏呼吸。Pass 2 的对白审读以五维逐维给证据，不写"对白平"这种虚话；对话标签黑名单（smiled and said / looked at her and said / said with a cold expression / laughed coldly / said with a cold snort）仍为硬项，命中即改。本章若 Pass 1 五项量化（对白字符占比 / 最长连续纯对白 / 对白后紧跟描写比例 / 对话标签多样性 / said 占比）任何一项踩红线却被放行，Pass 2 要**优先回修这些章节**。
- **第三人称自指**：角色指代自己时用 your uncle / your husband 等第三人称，只有在明显逗弄/俏皮语境保留；普通情境指自己必须改为 me / I。
- **章末钩子**：对照 [章末钩子八类](chapter-hooks.md) 判定 —— 决定瞬间 / 物证出现 / 问句悬浮 / 行动悬置 / 信息揭露 / 身份反转 / 倒计时 / 感官冲击。本章末 3 行能否明确归入八类之一？是否踩反面黑名单（总结式 / 预告式 / 情绪抒发式）？本批次 5 章内同类型钩子是否超过 2 次？批次末章是否用了"决定瞬间 / 物证 / 身份反转 / 倒计时"四种强钩子之一？任一项不合格就重写该章末。
- **残留扫描**（交付前硬项）：
  - 拼音姓名：Chen / Liu / Wang / Zhang / Zhao + 名；Mrs. Chen / Tessa Liu 这类"英文名+中文姓拼音"
  - 中文地名音译：Ning City / Beijing（未授权保留的）
  - 中式称呼：Young Master / Young Miss / Madam / Director Lu / Lawyer He / Big Boss
  - 公制残留：km / kg / cm / ℃ / 公里 / 公斤 / 米 / 摄氏度 / 元 / 人民币
  - 中式日常载体漏换：筷子 / 油条 / 豆浆 / 民政局 / 拜堂 / 红包 / 微信 / 微博 / 抖音（按本书本地化深度统一处理）
- **体验与范围**：冲突、压力、选择与后果是否连贯；是否兑现本轮任务，是否多写了未授权章节。

## 敏感红线清单

以下内容不得出现在正文（含对白、内心独白、叙述）：
- 对穆斯林 / 伊斯兰教的贬损
- 恋童
- 对未成年人的性骚扰
- 虐待儿童
- 绑架未成年人
- 部落歧视

涉及歧视、宗教和政治对立：中立化翻译，不放大对立。品类卖点（dark romance / 黑帮 / 狼人）保留胁迫张力与粗粝语气是允许的；dubcon 可留，实质 non-con 不得被浪漫化；未成年主角零性描写。

## 交稿前自查清单

每批合并稿交付前，用全文搜索过一遍：

1. 专名全书唯一译法（人名/地名/机构/道具）
2. 无中文残留（拼音姓氏、中文地名、中式称呼）
3. 无翻译腔（大声读出来会不会卡）
4. 英文姓名使用节奏正确（首次全名，之后只用名；疏远/正式用 Mr./Ms.+姓；不滥用全名）
5. 公制→英制已全部换完
6. 社交媒体已按目标市场替换（微信→iMessage/WhatsApp；微博→X；抖音→TikTok）
7. 章末钩子类型分布合理，没有连续两章同类型
8. POV 全程一致，承载角色与项目索引登记一致
9. 敏感红线清单无触碰
10. 术语表已同步更新本批新增专名

## 平淡诊断（正文平淡时怎么救）

**正文平淡不是语言问题，是设计问题**。审到平淡章节时按下面顺序排查，禁止反向：

1. **先查章纲**：本章设计的事件链本身是不是没冲突？人物有没有明确目标？目标前面有没有阻力？阻力产生的选择有没有代价？—— 章纲是"两人吃饭聊天"，怎么写都平淡。
2. **再查场景设计**：关键场景是不是集中在少数几段？有没有把高潮场景写得太短、过场场景写得太长？场景有没有让人物做选择，还是只在描述？
3. **再查人物声音**：对话是不是都一个口吻？有没有潜台词？
4. **最后才查描写**。

**禁止的错误救法**：
- ❌ 加形容词 / 加比喻 / 加排比 → 只会让稿件更冗
- ❌ 加心理描写 / 加回忆 → 只会中断节奏
- ❌ 拉长章节字数 → 只会稀释原本就少的戏
- ❌ 加短对白来回 → 只会制造更多水对白（见 [dialogue.md §一](dialogue.md)）

**正确的救法**：
- ✓ 回改章纲，砍场景、合场景、提前关键事件
- ✓ 给人物加目标或加阻力
- ✓ 把本章决定性时刻从"发生"改成"被选择"（人物面临两难）
- ✓ 把本章末钩子类型换掉（对照 [chapter-hooks.md](chapter-hooks.md) 八种类型）
- ✓ 对白被诊断为"水"时走 [dialogue.md §二](dialogue.md) 的五维修法，不要加短对白

诊断结论落到 Pass 2 问题清单，具体到章节段落，不交"整体感觉平"。

## 问题闭环

对每个实质问题给出原文/稿件位置、问题、原因、修法和修后检查。需要修订就落实到稿件后复查；若还不能解决，交付时列出，不宣布全部通过。语言自然度的模型审校是编辑判断，不能冒称母语读者实测；工具读取回执也不证明方法已应用。

例：把叙事里的"亲属安排职位"改成陌生机构直接调动，但没有写谁有权调动和主角为何接受，应回修动机与权限，不是在报告里勾选"制度已本土化"。

## 最终交付

最终交付以作者能阅读的正文为主，另给简短说明：本轮范围、关键改造、已修问题、尚未核实或需作者决定的事项，以及当前版本。

逐章稿按 `03-chapters/ch???-???/ch???.md` 保存；每完成 5 章出一个合并审查稿 `03-chapters/ch???-???/ch???-???.md`（只拼接不润色，顶部附本批交付说明）。

本地文件写成功只算文件已保存；平台写入必须有候选 ID 和回读，正式采纳另需作者决定。不要用一堆准备报告替代试稿，也不要把每天查表与一致性维护交回作者。
