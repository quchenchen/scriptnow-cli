# 海外网文研究依据与适用边界

本 Skill 限网络文学。核心材料是作者提供的 Accardi 与 Alpha Things 网文文本，另补海外网文平台实际可读章节。不能把传统出版小说样章、广告量或平台简介当作网文连载效果证据。研究记录在仓库 docs/research/webnovel-localization-2026-09-28.md；运行无需访问私人原著或仓库。

Accardi 精读十二章与尾声：相遇由有情感意义的赌注与社交压力推动，职场能力跨场域兑现，救援之后仍有信任和生活重估。可借鉴的是关系义务、选择代价与事件余波；不是复制黑帮身份、占有行为或固定结局。

Alpha Things 按十六组跨阶段范围细读：感知、通讯、身份和伴侣规则改变人物的资格、误判、行动与关系。也发现需回查的语言失误、身份漂移、过快概述和后段新规则。方法应检查机制是否影响因果及其限制，不能把 mate 当作动机或同意的万能解释。

两部长篇均未全书通读，作者/版本/销量未独立核验，不冒称全体海外网文标准。简介只支持卖点观察，开头只支持局部设局，不能据此宣布整书兑现或市场验证。

这些观察提供判断问题，不是模板。每章可以悬念、局部兑现、关系余波或停顿结束，按当前连载承诺决定。没有固定字数、反转次数、甜蜜互动数量和普遍付费截点。来源不足就标假设，遇到反例修订方法，不增加机械禁令。

## 原平台正文补充

以下仅支持已读章节的局部工艺，不支持销量、母语或付费留存结论。平台作者身份不等于作者国籍。

- [Goodbye, My Alpha 第1章](https://www.goodnovel.com/book/Goodbye-My-Alpha_31000918301/Chapter-1_11169832)与[第2章](https://www.goodnovel.com/book/Goodbye-My-Alpha_31000918301/Chapter-2_11169833)，Grogan：关系认知改变推动离开决定，随后场面进一步检验决定；不能概括所有女频都应密集背叛。
- [Alpha Raven 第1章所在作品页](https://www.goodnovel.com/book/Alpha-Raven_31000080303)与[第2章](https://www.goodnovel.com/book/Alpha-Raven_31000080303/CHAPTER-2-Her-Strange-Aura_836475)，_sleepie_head_：领地异常带来报告压力，回答旧问题后提高身份谜题层级；不能只拖延同一疑问。
- [Mother of Learning 第4章中后段](https://www.royalroad.com/fiction/21220/mother-of-learning/chapter/301788/4-stars-fell)与[第5章开头](https://www.royalroad.com/fiction/21220/mother-of-learning/chapter/301795/5-start-over)，nobody103：危机转为可测试的规则谜题，关系选择将人物带入机制；不是每章升级数值，也不提前解释全书规则。
- [Shadow Slave 第1章所读段落](https://www.webnovel.com/book/22196546206090805/59583457017254387)与[第2章](https://www.webnovel.com/book/22196546206090805/59606162361867867)，Guiltythree：资源差距影响试炼准备，弱势开局的落差形成行动期待；表面弱能力不等于最终能力结论。

比较相邻章节时问：上章留下的具体期待，在下章被回答、改变、限定，还是只是重复？情绪变化有什么新证据或行动代价？这些是检验问题，不是每章必须照走的顺序。按目标子类型选择有关样本，不能将狼人关系、循环成长与系统生存混成统一模板。

## 编辑手册的吸收边界

作者补充的世界观编辑手册用于组织决策，不作为网文正文或当前制度证据。吸收先定世界框架、按需展开领域、持续维护问题的做法；固定物价、地名/节日/习语替换表和周期复盘不继承。具体方法见 [世界框架](world.md)。旧手册的角色身份与已形成命名不能覆盖当前原著和作者决定。
