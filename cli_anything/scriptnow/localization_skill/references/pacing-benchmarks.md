# 节奏标杆：按品类拉片、按作者定基线

> 本文件给 agent 一个**可操作的拉片协议**：输入是作者指定的 1-3 本对标作品，输出是本项目的节奏基线（章长 / 场景数 / 对白密度 / 钩子类型分布 / 高潮间距）。
>
> **只学节奏与结构，不复用情节/人物/对白/世界观** —— 版权红线请见 §五。
>
> 当前 skill 版本：`v1.9.0`。本文件首次引入。

---

## 一、为什么需要拉片

**不拉片的后果**：agent 凭"romance 应该这样写"的通用印象写稿 → 读者读起来**像所有 romance 又都不像** → 作者很难说具体哪里不对，只能说"感觉不行"。

**拉片能给出**：
- 本品类的**章长中位数**（romance ≠ werewolf ≠ mafia ≠ billionaire）
- 本品类的**对白密度基线**（verse vs prose → 直接影响 dialogue.md 阈值校准）
- 本品类的**章末钩子类型偏好**（werewolf 多用"身份反转"，romance 多用"决定瞬间"）
- 本品类的**高潮间距**（一个"高能点"要几千词出现一次）

有了这个基线，审校和批次复盘才有**可对比的数字**，不再是空口评议。

## 二、拉片协议（agent 怎么拉）

**前置条件**：
- 作者已经给出 1-3 本对标作品的**全文或至少前 5-10 章**
- 作者**明确同意**"只学节奏不复用内容"的版权红线

**步骤**：

### 步骤 1：机械测量（agent 自写一次性脚本）

对每本对标作品，统计以下**九个数字**：

| 字段 | 定义 | 示例 |
|---|---|---|
| 章数 | 对标作品一卷/一部的章节总数 | 60 |
| 章长中位数 | 单章字符数中位数 | 2800 |
| 章长四分位距 | p25 和 p75 | 2200 / 3400 |
| 对白字符占比 | 全书对白字符数 ÷ 全书字符数 | 42% |
| 场景数/章 | 用 `*** / --- / ###` 等分隔符或大跨时空切换识别 | 1.6 |
| 对话标签多样性 | 全书去重计数 | 24 |
| said 占比 | said ÷ 全部对话标签 | 58% |
| 高能词密度 | heart / breath / cold / fire / silence 等感官词 ÷ 全文词数 | 0.9% |
| 章末最后 3 行字符数中位数 | 快速定位钩子强度 | 180 |

**脚本提示**：agent 用正则直接硬算，不要调用模型；跑完存到 `05-research/benchmark-[作品名].md`。

### 步骤 2：人读抽样（agent 逐章读，不要扫读）

对**每本对标作品的前 5 章 + 中段随机 2 章 + 全书最后 1 章**，人读抽样**七项**：

- **章末钩子类型**（对照 `chapter-hooks.md` 八种）
- **本章场景骨架**（几个场景 / 每场谁在场 / 场景之间怎么切）
- **高能点位置**（本章情绪 / 冲突 / 悬念的峰值出现在第几段）
- **叙事视角**（第一人称 / 第三人称有限 / 多 POV 切换）
- **内心独白与动作的比例**（感觉是在读她的脑子，还是在看她做事）
- **信息释放节律**（每章平均抛出多少个新信息 —— 新人物 / 新线索 / 新反转）
- **语言印记**（最高频的句式 / 感叹词 / 俚语密度 —— 用于声线差异参考）

**输出**：每本对标作品一份 `05-research/pacing-[作品名].md`，不超过 500 字 —— 把发现的节奏特征说清楚，不是复述情节。

### 步骤 3：合成基线（给本项目用）

把 1-3 本对标作品的九数字 + 七项抽样 **合成成本项目基线**：

| 项目基线字段 | 取值方法 |
|---|---|
| 目标章长 | 对标作品章长中位数的 90%–110% |
| 目标场景数/章 | 对标作品的中位数 |
| 对白密度目标 | 对标作品平均值 ± 5%（落到 `dialogue.md` 的阈值区间） |
| 章末钩子类型分布 | 对标作品前 5 章的分布（例："4 决定瞬间 + 2 物证 + 2 身份反转 + 2 问句") |
| 每批 5 章信息释放节律 | 对标作品每 5 章新信息数的中位数 |
| 高能点间距 | 对标作品一章里高能点出现的平均段落位置 |

**存**：`01-reference/project-pacing-baseline.md`。此文件作为后续**每章 Pass 1 的校准参照**，不是硬指标 —— 作者可以随时修改。

## 三、品类预装标杆建议清单（作者可覆盖）

**作用**：作者刚开项目、还没锁定对标作品时，agent 给以下**初始候选列表**（从当前 webnovel 市场实际流通的热门书中抽样，覆盖主要品类）。**不是硬性指定，仅作"你要不要先拉这几本看看"的建议**。

> 清单每半年应**由作者或 agent 同步到当前市场流通情况**，自检协议到期触发提醒。

### 现代 Romance / Billionaire

- *The Billionaire's Contract Bride* 类
- *Marriage of Convenience* 系列（Dreame / GoodNovel 高流通）
- Catharina Maura 作品线

### Mafia Romance

- *Twisted* series（Ana Huang）
- *The Sweetest Oblivion*（Danielle Lori）
- 作者投放的 Accardi 样本 —— 已存在 `05-research/` 可复用

### Werewolf / Shifter

- *Alpha's Rejected Mate* 类（Dreame / GoodNovel 高流通）
- *Fated to the Alpha* 类
- H.D. Carlton 相关作品（非严格狼人但节奏可参照）

### Revenge / Divorce

- 作者投放的《家庭的牺牲品》《法式背叛》《爱是寂静的迁徙》 —— 已存在 `05-research/` 可复用
- *The Substitute Bride*（divorce + revenge 混合）

### Fantasy Romance / ACOTAR 风

- Sarah J. Maas 的 ACOTAR series（节奏参考，不复用世界观）
- Rebecca Yarros 的 Fourth Wing

### Dark Romance / Explicit

- Pepper Winters 作品线
- 作者投放的 `18！描写.md` 片段 —— 情欲场景节奏的核心参照

**作者动作**：
- 想用预装清单：从以上**选 1-3 本**，或自行提供 1-3 本其他作品，告诉 agent 启动拉片
- 不想拉片：直接跳过 —— 本文件不是前置门禁，是**提供能力**而不是强制流程

## 四、拉片成果如何融入创作流程

| 阶段 | 用在哪里 |
|---|---|
| **立项**（workflow.md §1） | 作者定品类时，agent 主动询问是否需要拉片；作者点头即进入步骤 1 |
| **设计全书大纲**（workflow.md §3） | 用步骤 3 合成的章数 + 高能点间距校准整书结构 |
| **章纲**（workflow.md §4） | 用章长中位数 + 场景数/章 校准每章体例 |
| **逐章写作**（workflow.md §6） | 每章完成后对照基线核对；偏差 > 25% 触发自检 |
| **Pass 2 批次审**（review.md） | 批次六维里加"节奏偏差"条目，用基线对照 |

**关键**：基线是**参照**不是**命令**。作者有权在任何时候说"这一章我就要写得长一点/短一点/慢一点"，agent 不要拿基线去反驳作者 —— 只在作者没特别指示时作为默认。

## 五、版权红线（agent 必须守）

**可以学的**：
- 章长 / 场景切分 / 对白密度 / 钩子类型 / 叙事视角
- 感官词频 / 高能点间距 / 信息释放节律
- 抽象的叙事手法与节奏模式

**绝不可以搬的**：
- 具体情节走向 / 人物设定 / 具体对白 / 世界观设定 / 独有象征系统
- 任何可以让读者反查到对标作品的**独特细节**（罕见名字组合 / 独家术语 / 独家道具）

**写入 reference 时的匿名化规则**：
- 抽出的节奏数据可以留对标作品名（作者需要知道基线来源）
- 抽出的手法说明**不能**带有对标作品的独特情节细节
- 任何对照样例，用 `[品类]类作品 A` / `对标作品 B` 的匿名方式标注

**疑义时** → 偏保守，问作者。
