# 文化重构与代表性试写

## 从叙事功能出发

先说明原作让读者期待什么、为谁焦虑、因什么受辱或获得释放。对当前关键事件追问：谁能决定什么，谁依赖谁，拒绝的代价是什么，人物知道什么，为什么现在行动，后果如何推动下一幕。名词相似不是功能等效。

分层用于发现问题，不作为填写指标：
- 表层：名字、称谓、单位、货币、日常物件。
- 中层：礼仪、幽默、隐喻、亲属称呼背后的关系距离。
- 深层：组织权力、资源依赖、继承与身份、人物动机、羞耻与荣誉、情绪兑现。

保留适用于本来就能成立的元素；解释用于陌生但重要的背景；迁移用于可由另一载体承担的作用；重构用于原制度与目标环境不兼容、必须重写事件链的部分。增译与减译必须说明补回或删去了什么功能，不能为了“快”剪掉行动理由。映射只覆盖真正迁移/重构的元素，不把每个名词做成表格。

## 把假设变成有依据的方案

目标读者需具体到语言地区、类型期待和阅读场景。观察来自少量样本就标明样本，不虚构市场数据、母语读者评价或机构规定。竞品拆解可借鉴冲突启动、信息差、情绪递进与留白；其原文不成为可复制素材，其商业曝光也不证明文化适配正确。

先写一段连贯方案，再按需要记录来源位置、原叙事功能、拟议载体、人物新动机、因果影响、依据与待核实项。作者保护的是事件、关系、效果还是具体载体，要按其原话理解；不能自行把“保留核心”解释成随意删改情节。

## 用反例检查迁移，而非套用示范情节

关系型网文里，家族命令若改成 pack 命令，要重新回答谁有资格命令、拒绝失去什么；若作者保护“自由选择的爱情”，命定强制反而可能损害主题。成长网文里，考试排名若改成系统等级，要问它是否仍能决定资源和行动资格；若只改变称谓就删除了努力与制度不公的联系，迁移并未成立。这些只用于暴露问题，不要求引入狼人或系统。

对核心舞台、职业、关系和能力，检查它还承载哪些后续接触机会、成长路径与类型卖点。局部制度合理化不能毁掉全书发动机；未读后文时标明待核实，不编造保护项，也不把例子当唯一解。实质改造简要区分原文事实、实验新增和作者已经认可的决定，不强制填表。

虚构名称不能掩盖现实机制错误：若仍标作真实国家的现实背景，影响主要事件的机构权限、职业路径与法律关系要有可靠依据，或明确列为待核实，不能宣布已经适配。真正架空的制度则需要作者同意背景边界，并维护内部自洽。无原文时只能给标明合成来源的改写/方法示范，不得将补写的章节交作原著译稿。

## 视角、声音与后果

分清客观事件、人物判断、叙述者归因与读者已知。改写不提前泄露，也不把反派解释或角色偏见登记成确定世界观。双视角只有增加不同认知时才有用，单视角可以保留沉默与误读。

人物能动性看其是否能观察、筹划、拒绝、忍耐或改变因果，不要求人人强势。亲密吸引、命定、同意、知情与责任分别判断；作者有意的黑暗关系不自动被净化，但不能用一句台词遮盖行动的后果。

迁移机制时检查它怎样被执行、有哪些限制和代价，关键时刻的新例外是否已有线索。重大事件的身体、情绪和关系余波要与后文一致，不把救援、复合或婚礼当自动清零。叙事可以延宕、留白或反讽，无须逐章产生规定数量的变化。

对白迁移其交涉、回避、试探、结盟等行动，保留人物各自的知识与资源；不是给每人加同样的俚语。删背景或闲聊前检查其声线、线索与文化功能在哪里承接。

## 本地俚语、口语与人物声线

充分融合目标地区的自然口语，包括俚语、习惯搭配、称呼、缩略、省略、玩笑、挖苦和回应节奏。先理解一句话在当场是套近乎、敷衍、试探、羞辱、威胁、维护面子还是表达亲密，再选择当地角色会用的说法。不能仅把中文成语换成英文成语，或把所有愤怒写成相同脏话。

同一人物在朋友、恋人、家庭、上司、陌生人面前可以切换语域；冲突升级或关系变近也会改变表达。把声音与年龄、职业、阶层经历和性格相连，不凭族裔标签机械指定方言。近距离叙述和内心独白可以承接角色口语；正式文件、机构通知或特定叙述体按其功能保持相应语域。

读目标网文的实际对话与可靠当代语料，核对有疑问的俚语的地区、年代、含义、冒犯程度和使用关系；只在一个平台见过不能认作全国通用。无证据时避免自造“当地流行语”，可先用自然通行口语完成并标出待核实表达。允许作者指定更强的地方色彩和粗粝度，不能为讨好假想读者擅自改变尺度。

审校时连读整段对话，判断回应是否接得住、潜台词是否改变、该人是否会在这个对象面前这样说。俚语有时字面可译但语用不对；词典正确不证明场景合适。不按每章几句、脏话比例或统一俚语表判断本土化程度。建立角色相关的称呼与惯用表达记录，允许自然变化，不让口头禅每章打卡。

## 试写验证

在获授权范围内选风险场景，先说明要验证的疑问。试稿应显示人物为何采取行动、新载体怎样施加压力、原有体验是否仍能产生。审查语言声音、POV 与信息释放，不把英语脏话数量或短句比例当作自然度。

失败就定位并回修方案或局部稿件；成功只能说明该样段的问题得到解决，不能宣称全书、全文化或全市场已经验证。作者只要三章，就完成三章及必要准备，不擅自扩写全书。


## 工具与能力边界

DSH 中用 `skill` 加载本技能；若目录不可发现，可调用 `scriptnow_localization_method` 或 `scriptnow translate method --section all --json` 读取同版完整方法。CLI 只返回方法，不调用模型、不登录、不创建项目；其他 Agent 可读取同样输出执行。references 按任务加载，不靠目录里“有文件”宣称已应用。

DSH 的 PDF/DOCX/XLSX 用 `scriptnow_read_document`，按 offset/limit 继续读取；其他环境用已有可信文档工具。原文、逐页阅读和扫描图像留在作者环境。制度事实需要核实且有搜索能力时查目标地区可靠资料；无此能力就列为未核实假设或与作者商定虚构背景，不把猜测写成真实制度。无需为本地工作安装平台依赖。

不按“西方人都怎样”改人物，不把广告投放量当作语言质量或商业成功证明，不照搬竞品正文。文学分析、受众判断、文化重构、语言精修和审校是检查视角，不要求七个角色或并行 Agent。平台逐章串行与人工采纳规则不变。
