# 批次生产协议（五章一组）

本文件补充单章循环之上的**批次级**生产节奏，吸收自编辑《套皮小说本地化生产 SOP》。单章循环见 [workflow.md §6](workflow.md) / [recreation-workflow.md ⑨](recreation-workflow.md)；本文件处理"从全书大纲走到稳定量产"中间的几个关键节点，避免写到后面才发现方向跑偏。

---

## 一、三层生产资料

**五章是生产批次，不是只规划眼前五章**。全书大纲必须一次性规划完（workflow §4 / recreation ⑦），批次只是生产单位。每次批次启动前，agent 要主动读三层资料，不在批次中临时补查：

### ① 全书基础设定（整本不变，只在作者改时同步）
- 项目索引 `01-plan/项目索引.md`（POV / 承载角色 / 批次位置 / 保护项）
- 角色档案 `01-plan/角色档案.md`（人名、身份、关系、声线）
- 世界观决策 `01-plan/世界观决策.md`（权力架构、能力规则、文化机关处理）
- 全书术语表（人名/地名/机构名/道具名 → 英文译名；见 [continuity.md](continuity.md)）
- 全书大纲 `01-plan/大纲.md`（主线、主要转折、感情线、结局、重要伏笔）
- 语言风格要求（见 [english-output.md](english-output.md)）

### ② 当前卷资料（按卷切换）
- 当前卷大纲（核心冲突、阶段目标、本卷伏笔）
- 当前 5 章细纲（每章：事件 / 冲突 / 情绪 / 钩子类型 / POV 承载角色）
- 本卷视角安排（默认单一第一人称；双 POV 的切章点）
- 本卷待兑现伏笔清单

### ③ 近期衔接资料（每批次更新）
- 上一组 5 章剧情摘要 `03-chapters/ch???-???/ch???-???-摘要.md`（事件链 / 决策 / 情绪位置）
- 人物最新状态表（见 [continuity.md](continuity.md) 的"人物当前状态表"）
- 上一组结尾实际文本（最后一章的最后一两段）
- 下一组需要承接的事件（上组埋的钩子如何接）

**不每次重读整本原著或全部历史正文**。三层资料是生产用的记忆体，agent 只在看到冲突（大纲里没有的新事件 / 人物状态表与正文对不上）时才回原文核对。

## 二、首批 5 章 Gate

**在决定批量生产之前，先把前 5 章当试写**。试译样段（workflow 阶段 5 / recreation ⑥后）验证的是**单场景**能否成立；首批 5 章 gate 验证的是**完整连载节奏**在目标市场能不能站住。两者都要做，顺序是：

```
单场景试译（高风险样段验证） → 作者确认方向
     ↓
首批 5 章试写（完整节奏验证） → 作者确认后再批量
     ↓
从第二批（ch006-010）起按批次生产
```

### 首批 5 章验收标准

**不是检查语法，而是判断能不能连载**。作者看首批合并稿时，重点看：

1. **开篇钩子**：前 500 词能不能抓住平台读者？冲突或悬念是否在第一章前半出现？
2. **人物声音**：主要角色的英文声线是否彼此清晰可辨？有没有写成同一口吻？
3. **节奏**：五章读完有没有真实推进？有没有短对话水章、注水章？—— 对白质量按 [dialogue.md 五维](dialogue.md) 判定，**五章里对白字符占比 / 最长连续纯对白 / 对白后紧跟描写比例等量化红线任一踩中，节奏就不过**。
4. **POV 承载**：承载角色（接诊里定的那个）能不能承担整本书？是否合适作者意图？
5. **英文自然度**：有没有翻译腔、拼音残留、公制残留、中式称呼残留？
6. **钩子分布**：五章末钩子是否都能归入 [chapter-hooks.md 八类](chapter-hooks.md) 之一？是否踩反面黑名单（总结式 / 预告式 / 情绪抒发式）？同类型钩子是否超过 2 次？第 5 章末是否用了"决定瞬间 / 物证 / 身份反转 / 倒计时"四种强钩子之一？
7. **品类卖点**：目标品类读者期待的场景在首批有没有初步兑现（狼人文有没有初步铺 mate bond 氛围、黑帮文有没有初步交代 family 结构）？若已拉片（[pacing-benchmarks.md](pacing-benchmarks.md)），**对照项目基线**判断章长/场景数/对白密度/高能点间距是否在 ±25% 带内。

### Gate 不通过怎么办

**不是"再加章"**，而是回头修：

- 人物声音没拉开 → 回 ⑤ 修角色档案声线差异化
- 节奏拖沓 → 回 ⑧ 修章纲，砍水场景，提前关键转折
- 开篇钩子不行 → 回 ⑦ 大纲 / ⑧ 首章细纲，重排事件顺序
- POV 承载不对 → 回接诊重定承载角色，前 5 章重写

**gate 没过就重写前 5 章；不要带着首批问题往第二批赶**，后面十章会把问题放大十倍。

## 三、批次生产循环（第二批起）

首批通过后，从 ch006 起按下面循环推进。每批次独立执行：

### 批次启动前（不可省略）
1. 读三层资料（§一），确认全书基础无变、当前卷未切换、近期衔接有上批摘要
2. 读本批 5 章细纲（ch???-???+4），确认每章钩子类型不重复、POV 承载一致
3. 读上一批合并稿顶部的"本批交付说明"中"下批需承接"段

### 批次写作中（按单章循环写）
按 [workflow.md §6 / recreation ⑨](workflow.md) 单章循环写，每章独立通过 10 项自查。

### 批次写作后（不可省略）
1. 把 ch??? ~ ch???+4 拼成合并稿 `ch???-???.md`（只拼接不润色）
2. 顶部写"本批交付说明"：覆盖区间 / 每章钩子类型 / 关键决策变更 / 待确认事项 / **下批需承接**
3. 更新 §四 的三份近期衔接资料
4. 交付合并稿，等整批作者反馈
5. 等反馈的同时可以把下一批 5 章细纲从全书大纲里拉出来、写出来，但**不开始写下一批正文**

## 四、近期衔接资料的维护

每批次写完**立即**更新三份文件（下一批 agent 就靠这三份衔接），不要攒到审稿时再补：

### 1. 上一组剧情摘要 `03-chapters/ch???-???/ch???-???-摘要.md`

每章一段，共 5 段，每段 150-300 字，覆盖：
- 本章发生的事件链（谁做了什么决定、代价、后果）
- 本章产生的新信息（谁知道了什么、谁还不知道）
- 本章埋下的伏笔 / 承接的伏笔
- 本章结尾的情绪位置（主要角色各自处于什么情绪）
- 本章末钩子类型与钩子内容一句话

摘要给下一批 agent 用，避免重读 5 章正文。摘要要**忠实于正文**，不能理想化、不能美化水章。

### 2. 人物最新状态表（追加到项目索引或角色档案尾部）

| 角色 | 当前所在地 | 当前情绪 | 本批关系变化 | 本批身体/财务状态 | 当前知识边界（知道什么，不知道什么） |
|---|---|---|---|---|---|

主要角色每批次更新一次；配角只在状态变化时更新。

### 3. 下一批需承接的事件

在合并稿"本批交付说明"末尾列明：
- 本批末钩子类型与下一批首章如何接
- 本批触发但未兑现的伏笔，下一批哪一章兑现
- 本批埋下但尚未明面的危机，下一批何时浮出
- 本批需作者确认的方向性问题（没确认之前不能拍板的）

## 五、分卷审核节点

全书 ≥ 2 卷时，每卷结束后插入一次**卷级审核**（区别于每章自查、5 章合并稿、全书终审）。卷级审核检查**跨批次**的事：

### 卷级审核六项

1. **卷目标达成**：本卷大纲设定的核心冲突和阶段目标是否真的推进到位？
2. **主线连贯**：卷内各批次之间有没有事件/因果断裂？
3. **人物弧光**：主要角色在本卷开头到结尾的变化是否有据可查？有没有性格突变？
4. **感情线节奏**：从心动→靠近→最大危机→和解的节拍，在本卷内是否均匀铺开？有没有偷跳阶段？
5. **伏笔收支**：本卷铺的伏笔 vs 本卷兑现的伏笔，有没有悬空太久的？下一卷能不能接？
6. **术语一致**：本卷新增的专名是否已登记全书术语表？已登记的译名有没有漂移？

### 卷级审核产物

- 卷审核报告 `04-review/卷N-审核.md`：问题清单 + 修订落点 + 回修后复查
- 更新全书大纲（本卷结束后，下卷大纲若有调整要写进 `01-plan/大纲.md` 的变更记录）
- 卷终人物状态表快照（存档，下卷复核用）

**卷终问题必须在下卷开始前修完**；带病进入下卷会让问题复利。

## 六、正文生成与质量审核分离

编辑 SOP 的硬原则：**正文生成和质量审核尽量分开**。单章循环里的"写完后 10 项自查"是机械项（拼音残留 / 公制残留 / 对话标签黑名单…），不是文学判断。

文学层面的质量审核另走一遍：

### Pass 1：生成
按单章循环写正文、过 10 项机械自查、落合并稿。

### Pass 2：文学审核（合并稿交付后 / 卷结束后 / 全书终审）
按 [review.md 审校维度](review.md) 过稿，重点：
- 对白是不是在推动信息差/权力博弈/关系温度（不是水对白）
- 场景有没有体验（不是只有事件堆叠）
- 人物有没有能动性（不是被情节推着走）
- 节奏起伏是否可读（不是平铺直叙）

**两遍用不同的检查镜片**：Pass 1 查错，Pass 2 查好不好看。两遍混在一起，查错会挤走查好看的注意力。

## 七、"平淡诊断"：正文平淡时怎么救

**正文平淡不是语言问题，是设计问题**。下列顺序排查，禁止反向：

1. **先查章纲**：本章设计的事件链本身是不是没冲突？人物有没有明确目标？目标前面有没有阻力？阻力产生的选择有没有代价？——如果章纲就是"两人吃饭聊天"，怎么写都平淡。
2. **再查场景设计**：关键场景是不是集中在少数几段？有没有把高潮场景写得太短、过场场景写得太长？场景有没有让人物做选择，还是只在描述？
3. **再查对白**：按 [dialogue.md 五维](dialogue.md) 过 —— 行动性 / 包裹层 / 潜台词 / 声线差异 / 节奏呼吸。**"大量短对话水剧情"是本 skill 的头号塌方**：问题从来不是对白太多，而是对白没被三层（动作预设 / 对白本体 / POV 反应）包裹 —— 中文原著的高密度短对白节奏不能逐句搬到英文，一搬就死。
4. **再查钩子**：按 [chapter-hooks.md 八类](chapter-hooks.md) 判定本章末是否成立。"章末没钩子"等于这一章白写 —— 平台读者翻不翻下一章就看章末那 3 行。
5. **最后才查描写**

**禁止的错误救法**：
- ❌ 加形容词 / 加比喻 / 加排比 → 只会让稿件更冗
- ❌ 加心理描写 / 加回忆 → 只会中断节奏
- ❌ 拉长章节字数 → 只会稀释原本就少的戏
- ❌ 加短对白来回 → 只会制造更多水对白（这是最常见的反模式，务必杜绝）

**正确的救法**：
- ✓ 回改章纲，砍场景、合场景、提前关键事件
- ✓ 给人物加目标或加阻力
- ✓ 把本章决定性时刻从"发生"改成"被选择"（人物面临两难）
- ✓ 对白按 [dialogue.md §二](dialogue.md) 五维修法：加包裹层、加潜台词、拉声线差异、调节奏呼吸
- ✓ 把本章末钩子类型换掉（对照 [chapter-hooks.md](chapter-hooks.md) 八类换一种更强的）

诊断结果要落到 Pass 2 的问题清单里，具体给到哪一章哪一段回修，不交"整体感觉平"的话。
